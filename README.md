# Sanskrit Depository

A GitHub Pages reading room for Sanskrit texts in Devanagari. Every word can be tapped for its sandhi split, grammar and English meaning.

**Nyāya darśana**

- Nyāyasūtra of Gautama with Vātsyāyana’s Nyāyabhāṣya
- Nyāyasūtra with Vācaspati Miśra’s Nyāyavārttikatātparyaṭīkā
- Gaṅgeśa’s Tattvacintāmaṇi, Śabdakhaṇḍa (Śabdaprāmāṇyavāda to Jātiśaktivāda)
- Annaṃbhaṭṭa’s Tarkasaṃgraha
- Tarkasaṃgraha with the Dīpikā, Nīlakaṇṭha’s Prakāśikā, the Bālapriyā and the Prasāraṇā

The site is plain HTML, CSS and JavaScript (`index.html`, `assets/`) reading pre-built data (`data/`). The e-texts are from GRETIL (CC BY-NC-SA 4.0). To rebuild the word analysis or add a text, see [`build/README.md`](build/README.md).
